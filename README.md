# ELF — Enhanced Learning Friend (Chatbot Agent)

ELF (Enhanced Learning Friend) is a Python-based conversational chatbot web application. It combines intent detection, named-entity extraction, sentiment analysis, web search, text summarization, weather and news integrations, and text-to-speech in a Flask interface.

> **Project status:** Personal/academic prototype. Some features depend on third-party APIs and a locally configured MySQL database. Search summaries are heuristic summaries of retrieved snippets, not generated by a large language model.

## Features

- **Conversational interface** served by Flask
- **Intent detection and NLP processing** for common user requests
- **Sentiment analysis** using VADER/TextBlob-related components
- **Web search** with result extraction and snippet-based summaries
- **Text summarization** utilities
- **Weather information** through OpenWeatherMap (requires an API key)
- **News headlines** through NewsAPI (requires an API key)
- **Text-to-speech** using gTTS
- **Conversation and analytics storage** in MySQL

## Tech Stack

- Python
- Flask and Flask-CORS
- MySQL (`mysql-connector-python`)
- NLTK, TextBlob, VADER Sentiment
- Requests and BeautifulSoup
- SymPy
- SpeechRecognition, gTTS, pyttsx3

## Requirements

- Python 3.10 or newer (use a version supported by the pinned dependencies)
- MySQL Server
- pip

Some audio dependencies, especially PyAudio, may require operating-system packages or a prebuilt wheel. If you do not need microphone input, you may omit/install that dependency separately after confirming which features you use.

## Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/chatbot-agent.git
cd chatbot-agent
```

### 2. Create and activate a virtual environment

**Windows (PowerShell):**

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
```

**macOS / Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

If PyAudio fails to install, consult its installation instructions for your operating system. It is only needed for microphone-based speech recognition.

### 4. Configure environment variables

Copy `.env.example` to `.env` and set your local MySQL credentials and API keys.

The application reads environment variables in `config.py`. For a local development setup, load `.env` in your shell or add `python-dotenv` and call `load_dotenv()` before importing `config.py`.

Example (PowerShell):

```powershell
$env:DB_HOST="localhost"
$env:DB_USER="root"
$env:DB_PASSWORD="your-local-mysql-password"
$env:DB_NAME="chatbot_db"
$env:OPENWEATHERMAP_API_KEY="your-openweathermap-key"
$env:NEWSAPI_KEY="your-newsapi-key"
```

Do not put real credentials in source files or commit `.env`.

### 5. Create the database

Create the database and tables using the SQL script:

```bash
mysql -u root -p < database/chatbot.sql
```

Update the database environment variables to match your MySQL setup.

### 6. Run the application

```bash
python app.py
```

Open [http://127.0.0.1:5000](http://127.0.0.1:5000) in your browser.

## API Integrations

| Integration | Purpose | Setup |
|---|---|---|
| OpenWeatherMap | Weather lookups | `OPENWEATHERMAP_API_KEY` |
| NewsAPI | News headlines | `NEWSAPI_KEY` |
| MySQL | Conversation and analytics storage | `DB_HOST`, `DB_USER`, `DB_PASSWORD`, `DB_NAME` |

The app can start without the optional weather/news keys, but those integrations will not return live data until valid keys are configured.

## Security and Privacy Notes

- This repository intentionally excludes the original virtual environment and local credentials.
- API keys and database passwords must be stored in environment variables, never committed to Git.
- Rotate any API keys that were previously stored in a shared or public source file.
- The current Flask application is a prototype: it enables CORS broadly, runs without authentication, and stores user messages/sentiment data. Do not expose it publicly or use real personal data until authentication, access control, input validation, privacy controls, secure deployment, and production database handling are implemented.
- Set `FLASK_DEBUG=false` outside local development and use a production WSGI server behind HTTPS.
